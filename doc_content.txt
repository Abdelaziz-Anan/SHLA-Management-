English Center Management System
Complete Technical & Functional Specification
I want you to build a complete professional web-based management system for an English language center.
The current center manages student groups, payments, attendance/session dates, and receipts manually on paper.
The goal is to completely replace the paper-based workflow with a modern, secure, responsive, mobile-first management system that can be accessed from Android phones, iPhones, tablets, and laptops through a web URL.
This must be a real full-stack production-ready application.
It must include:

1. IMPORTANT: AUTHENTICATION AND SECURITY
This system must NOT be publicly accessible just because someone knows the URL.
The application must have a secure Login page.
Nobody should be able to access the dashboard or any internal page without successfully logging in.
The system must support:
Username/email
Password
Secure authentication
Session management
Protected routes
Role-based permissions
Logout
Password change/reset
Account activation/deactivation
The system must use real authentication.
Do NOT create a fake frontend-only login.
Do NOT store passwords in plain text.
Use Supabase Auth or another secure authentication mechanism.

53. FINANCIAL LOGIC
Centralize financial calculations.
For each student:
Total Paid =SUM(valid payments)
Remaining =Course Price - Total Paid
For the center:
Total Collected =SUM(valid payments)
Manager Received =SUM(valid payments where destination owner = Manager)
Center/Assistant Received =SUM(valid payments where destination owner = Center)
Remaining With Center =Center/Assistant Collected
Settlements Delivered to Manager
